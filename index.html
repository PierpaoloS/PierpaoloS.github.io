Sincronizza tra dispositivi

Con lo stesso URL e lo stesso codice su PC e telefono, i dati si allineano dal cloud (Firebase, gratis). Si sincronizza all'apertura dell'app e a ogni modifica.

Come si configura (una volta sola)
  1. Vai su console.firebase.google.com e crea un progetto (gratis).
  2. Build → Realtime Database → Crea database.
  3. Copia l'URL del database (es. https://xxx-default-rtdb.firebaseio.com) e incollalo qui sotto.
  4. Nella scheda Regole incolla questo e pubblica:{ "rules": { "sync": { "$c": { ".read": true, ".write": true } } } }
  5. Metti lo stesso URL e lo stesso codice anche sul telefono.
